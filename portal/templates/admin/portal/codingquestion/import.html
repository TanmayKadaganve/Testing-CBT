    Before You Import Coding Questions

    • Use an .xlsx workbook containing both the Coding Questions and Test Cases worksheets.
    • Enter one row per question on the Coding Questions sheet, and one row per testcase on the Test Cases sheet. Repeat the Section and Q No on each testcase row to pair them with the appropriate question.
    • Section names must match coding sections in the selected exam. Questions with candidate drafts or submissions are safely skipped to protect student examination data.
