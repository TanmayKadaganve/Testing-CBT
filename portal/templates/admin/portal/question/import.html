    Before You Import MCQ Questions

    • Use an .xlsx or .csv file with columns for Section, Q No, Question, Option A through Option D, Correct, and Marks.
    • The Section column must exactly match the title of an MCQ section configured in the target examination.
    • Re-importing an existing question number updates that question. Questions that candidates have already answered are safely left unchanged to preserve exam integrity.
